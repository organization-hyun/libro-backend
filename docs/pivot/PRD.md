# PRD - 모바일 퍼스트 기록/아카이빙 MVP

## 목표
사용자가 매일 기록하는 습관을 만들고, 기록을 자산으로 축적/회고할 수 있도록 돕는다.

## 성공 지표(MVP)
- D1 리텐션(다음 날 재방문)
- 주간 활성 일수(주 3회 이상 기록)
- 완료율(작성 화면 진입 대비 저장 완료)

## MVP 필수 기능
### 인증
- 이메일 매직링크 로그인

### 기록(Entry)
- 생성/조회/수정/삭제
- 에디터 자동저장 + “저장됨” 표시
- 카테고리: 일기/독서/영화/생각(확장 가능)
- 태그(선택)
- entry_date(사용자 로컬 날짜 기준)

### 오늘의 프롬프트
- 카테고리별 랜덤 질문 1개 제공
- (선택) 하루 N회 프롬프트 바꾸기

### 작성 후 보상 카드(저비용)
- 요약 1문장
- 키워드 3개
- MVP에서는 룰 기반(LLM은 2차/옵션)

### 아카이브
- 캘린더/리스트 뷰
- 키워드 검색(내용)
- 카테고리 필터
- 월간 리캡(키워드 Top, 카테고리 분포, 대표 기록)

### 공유(최소 소셜)
- 공개 범위: private / unlisted(링크) / public
- share_slug 기반 읽기 전용 공유 페이지

## MVP 비목표(Non-goals)
- 모임 운영(권한/멤버/일정/토론)
- 좋아요/댓글/팔로우
- 푸시 알림

## 제약
- 피벗 과정에서 가능한 한 기존 흐름을 깨지 않도록 호환 레이어 우선
