# 피벗 컨텍스트 (CONTEXT)

## 왜 피벗하나
사용자가 하루하루의 생각을 다양한 소재(일기/독서/영화/일상 생각 등)로 기록하고,
이를 아카이빙하여 회고/추억을 되짚을 수 있도록 돕는 서비스로 확장하고자 합니다.
원하면 기록을 공유하고(향후) 모임으로 연결할 수 있게 합니다.

## MVP에서 가장 중요한 것
**모바일 퍼스트(PWA) + 기록 작성 루프**가 최우선입니다.
사용자가 “3초 안에 쓰기 시작”할 수 있어야 합니다.

## MVP 우선순위
1) 매일 기록 루프
- 홈(오늘의 프롬프트) → 작성(자동저장) → 작성 후 보상 카드(요약/키워드)
2) 아카이브
- 캘린더/리스트 + 검색 + 월간 리캡
3) 최소 소셜
- 공유 링크(읽기 전용 페이지) + 공개 범위(비공개/링크공유/공개)

## 2차(미루는 것)
- 모임 운영(가입/권한/일정/토론 스레드 등)
- 좋아요/댓글/팔로우
- 푸시 알림(필요 시 추가)

## 도메인 매핑
- 기존 “독서 기록(ReadingLog)” → 일반화된 “기록(Entry)”
- 기존 “책(Book)” → “소재(Material)”로 확장하거나, 초기에는 Book을 소재의 한 종류로 유지
- 모임(Club)은 레포에 남기되 MVP에서는 확장하지 않음(공유 링크가 MVP 소셜)
